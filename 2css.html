CONCEPT 1

1. Element Selector

English: Tag name se matching elements target hote hain.

Hindi: Tag name se matching elements target hote hain. Is concept ko practical website me use karte waqt syntax, browser behavior aur responsive effect ko samajhna important hai.

Syntax / Example

/* Element Selector */
.demo {
  padding: 20px;
  margin: 10px;
  color: #2563eb;
}

Correct Example

Use the property/value according to the design requirement and keep the rule readable and reusable.

Common Mistakes

  • Property name ya value ki spelling galat karna.
  • Selector ko unnecessarily complex banana.
  • Responsive screens par output test na karna.
