4. CSS Units

LoOPCode • Learn CSS with Explanation + Practice

1. Why units are needed

English: CSS values use units to describe lengths and sizes.

Hindi: px, %, em, rem, vw aur vh ka correct selection responsive design ke liye important hai.

Concept / Example:
100px
💡 Common Tip: Property names aur values ko carefully check karo; semicolon aur braces miss na karo.

2. Absolute Units

English: px is the most common screen-oriented absolute unit; cm, mm and in are mainly useful for print.

Hindi: Fixed visual details jaise border thickness ke liye px useful hai.

Concept / Example:
200px
💡 Common Tip: Property names aur values ko carefully check karo; semicolon aur braces miss na karo.

3. Percentage

English: % is relative to an appropriate containing dimension.

Hindi: Parent ke size ke according width/height adjust karne ke liye percentage useful hai.

Concept / Example:
50%
💡 Common Tip: Property names aur values ko carefully check karo; semicolon aur braces miss na karo.

4. em and rem

English: em depends on the element's font context; rem is based on the root html font size.

Hindi: rem consistent typography ke liye aur em component-relative sizing ke liye useful hai.

Concept / Example:
Responsive text
💡 Common Tip: Property names aur values ko carefully check karo; semicolon aur braces miss na karo.

5. Viewport Units

English: vw and vh represent percentages of the viewport width and height.

Hindi: Full-screen hero sections aur responsive sizing me vw/vh ka use hota hai.

Concept / Example:
Hero
💡 Common Tip: Property names aur values ko carefully check karo; semicolon aur braces miss na karo.

6. Modern responsive units

English: vmin, vmax, ch and ex can help with specialized responsive sizing.

Hindi: ch text line length ke liye useful hai; vmin/vmax viewport dimensions ke relative responsive sizing dete hain.

Concept / Example:
Readable text width
💡 Common Tip: Property names aur values ko carefully check karo; semicolon aur braces miss na karo.
