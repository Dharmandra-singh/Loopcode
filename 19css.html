CONCEPT 1

1. Bootstrap

English: Bootstrap is an important CSS concept used in modern, responsive and maintainable web development.

Hindi: Bootstrap ko practical website me use karke design ko responsive, interactive aur professional banaya ja sakta hai. Is concept ko values change karke practice karo.

Example

/* Bootstrap */
.demo {
  padding: 24px;
  background: #dbeafe;
  color: #1e3a8a;
  border: 2px solid #2563eb;
  border-radius: 12px;
}

Common Mistakes

  • Property/value spelling ya syntax mistake.
  • Unnecessarily complex selectors or rules.
  • Mobile screen par output test na karna.
